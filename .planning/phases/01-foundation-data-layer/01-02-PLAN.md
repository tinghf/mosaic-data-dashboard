## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user/sidebar → config | Sidebar override string flows into `resolve_data_root()` which calls `Path(override).expanduser()`. Single-user local dashboard; no shell exec, no symlink-escape concerns. |
| config.toml → config | TOML file read read-only; no eval, only `tomllib.load`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-04 | Tampering | `resolve_data_root()` override path | accept | Single-user local context (PROJECT.md "Authentication / multi-user state — out of scope"); read-only dashboard cannot leverage path injection to harm. |
| T-01-05 | DoS | `SchemaMismatchError` re-raised on every cache miss | accept | Per RESEARCH.md P8, Streamlit does NOT cache exceptions — error re-raises until file is fixed. Acceptable: error makes the problem visible. |
| T-01-06 | Information Disclosure | `logging` formatter includes file path | accept | Local dashboard, stderr-only output; no log shipping. |
</threat_model>
