<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Streamlit widget -> Python session_state | The selectbox's `key=` binding causes Streamlit to write the chosen ISO3 directly into `st.session_state[COUNTRY_SESSION_KEY]`. Options are constrained to `iso3_options` — only the 54 ISO3s ever appear; user cannot inject a free-form value. |
| filesystem -> Python | No new filesystem reads in this plan. `shapefiles.available_countries()` (Phase 1) is called once for the drift check. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-07 | Spoofing | selectbox value | accept | The widget options are programmatically derived from the static `COUNTRIES` tuple in source code; a user can only pick from those values. No free-text injection. |
| T-02-08 | Tampering | session_state | accept | `st.session_state` is in-memory and per-session. No cross-session attack surface. |
| T-02-09 | Denial of Service | drift-check loop | mitigate | `warn_if_drifted_from_shapefiles` is O(54) and pure-Python; `shapefiles.available_countries()` does ~54 `Path.stat()` calls. Total runtime ≈ low single-digit ms. Safe to call on every rerun. |
</threat_model>
