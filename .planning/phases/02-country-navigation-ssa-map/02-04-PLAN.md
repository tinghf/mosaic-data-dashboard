<objective>
Implement `src/mosaic_dashboard/pages/01_SSA_Map.py` — the dedicated SSA map page (D-34). The page loads the AFRICA_ADM0 GeoDataFrame via Phase 2's new `load_africa_geometry()`, renders it as a clickable folium.GeoJson choropleth (CartoDB Positron tiles per UI-SPEC), and wires the click event to `st.session_state[COUNTRY_SESSION_KEY]` — the same slot the sidebar selectbox binds to. Bidirectional sync (MAP-02) is achieved by both inputs writing to the same key.

The implementation MUST encode three pitfall mitigations:
1. The DBF column for ISO3 is `iso_a3` (lowercase, underscore) — NOT `ISO3` or `ADM0_A3` (RESEARCH P7).
2. The click handler MUST validate the clicked ISO3 against `country_metadata.ISO3_SET` before writing to session_state — otherwise clicking ESH (Western Sahara) or `-99` (Somaliland) leaks an invalid value that crashes the selectbox (RESEARCH P10, CRITICAL FINDING #2).
3. `st_folium(...)` MUST pass `returned_objects=["last_active_drawing"]` to slim the rerun payload and prevent pan/zoom-triggered reruns (RESEARCH P3).

Purpose: Implements MAP-01 (SSA map from `processed/shapefiles/AFRICA_ADM0` with clickable countries), MAP-02 (highlight selected country + bidirectional sync with the sidebar dropdown), and the click-as-alternate-picker half of NAV-01. Implements D-21 (folium + streamlit-folium consumer), D-23 (map uses folium; Phase 4 OVERLAY will use plotly/altair for time-series — no requirement to unify visual language across libs in v1), D-34, D-35, D-36, D-37.

Output:
