# Phase 2 — UI Design Contract

> Visual and interaction contract for the country picker, the SSA map page, and the page-shell pattern that Phase 3-7 inherit. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

Audience: MOSAIC team modelers (single-user, local, offline). No marketing surface, no formal brand — the UI must feel like a competent internal data tool: information-dense, fast to scan, zero decorative chrome.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Streamlit defaults — no custom theme, no `.streamlit/config.toml`) |
| Preset | not applicable (shadcn gate skipped — Python/Streamlit project, not React/Next.js/Vite) |
| Component library | Streamlit 1.57 native widgets + folium 0.20.x via streamlit-folium 0.27.x (locked D-21) |
| Icon library | none (no decorative icons; Streamlit's built-in status glyphs on `st.warning`/`st.error`/`st.info` are sufficient) |
| Font | Streamlit default (system sans: `"Source Sans Pro", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, ...`) |
| Theme | Streamlit auto theme (respects user OS light/dark preference). Do NOT pin a theme in this phase — defer to user preference. |

**Why no custom CSS:** Streamlit's defaults are appropriate for an internal inspection tool. Every custom-CSS hack we ship is one more thing Phase 3-7 must work around. Deviate only where Streamlit's default actively hurts the use case (none identified for Phase 2).

## Spacing Scale

Streamlit owns most spacing via its internal block layout. We declare the scale below for any place we control (folium map height, `st.write` vs `st.caption` rhythm, sidebar divider placement) so Phase 3-7 inherit it.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline-text gaps inside captions, sidebar help tooltips |
| sm | 8px | Compact element spacing (caption-to-figure, gap inside `st.columns`) |
| md | 16px | Default vertical rhythm between Streamlit blocks (matches Streamlit default `gap`) |
| lg | 24px | Section padding (sidebar divider top/bottom margin) |
| xl | 32px | Layout gaps between page title and first body element |
| 2xl | 48px | Major section breaks (e.g., between map and any future below-map content) |
| 3xl | 64px | Page-level spacing — reserved; not actively used in Phase 2 |

Exceptions:
- **Map container height:** 600px fixed (see Map page layout below). 600 is not on the 4-multiple grid in the conventional sense but IS a multiple of 4 (150 × 4). Streamlit-folium requires a pixel height — percentages do not work with iframe-based folium.
- **No custom margins/paddings via CSS injection.** If a default looks wrong, file a Phase 7 polish ticket rather than patch with CSS.

## Typography

Streamlit owns typography. We declare the four roles below as the canonical mapping from Streamlit primitives to semantic role. Sizes match Streamlit 1.57 default theme.

| Role | Size | Weight | Line Height | Streamlit primitive |
|------|------|--------|-------------|---------------------|
| Body | 16px | 400 (regular) | 1.6 | `st.write` / `st.markdown` body text |
| Label | 14px | 400 (regular) | 1.5 | `st.caption`, widget labels, help-text tooltips |
| Heading | 24px | 600 (semibold) | 1.3 | `st.header` (sidebar headers, in-page section headers) |
| Display | 36px | 700 (bold) | 1.2 | `st.title` (one per page, at the very top) |

Weights used: exactly 2 — **400 regular** (body, label) and **600 semibold** / **700 bold** for headings (Streamlit's bold-vs-semibold choice is internal to its theme — we treat both as "heading weight" for the purpose of the 2-weight contract).

Body line-height of 1.6 is Streamlit's default and is appropriate for the data-dense caption strings Phase 7 will add ("WHO cholera cases for Angola (1949-2024). Source: ..."). Do not override.

## Color

The "60/30/10" surface split below describes the rendered Streamlit page in **light theme** (which is the most common default; the contract carries to dark theme via Streamlit's auto-inverted palette — the *roles* are stable, the hex values invert).

| Role | Value (light theme) | Value (dark theme) | Usage |
|------|---------------------|--------------------|-------|
| Dominant (60%) | `#FFFFFF` | `#0E1117` | Main body background, map background under unfilled regions |
| Secondary (30%) | `#F0F2F6` | `#262730` | Sidebar background, country fill (unselected, see map styling) |
| Accent (10%) | `#FF4B4B` (Streamlit primary) | `#FF4B4B` | **Selected country highlight on the map only** |
| Destructive | `#FF4B4B` | `#FF4B4B` | Not used in Phase 2 — no destructive actions exist |

**Accent reserved for (explicit, exhaustive list — every other interactive element uses Streamlit defaults):**
1. Selected country **fill color** on the SSA map (folium GeoJson `style_function` returns this hex when `properties.iso3 == selected_iso3`).
2. Selected country **stroke color** on the SSA map (same condition; stroke width also increases — see Map Styling below).

That is the entire accent budget for Phase 2. Picker selectbox styling, hover states, links, etc., all use Streamlit defaults (no custom color).

**Why a red accent on a map of African countries?** The accent must be unambiguous against the neutral light-gray country fills and against any CartoDB Positron tile color. `#FF4B4B` (Streamlit's primary) passes WCAG AA contrast against both `#F0F2F6` and `#FFFFFF`. We additionally rely on stroke width (not color alone) for redundancy — see Accessibility below.

## Map Styling Contract (Phase-2-specific, sub-spec of Color + Visuals)

This is the prescriptive visual contract for the folium map on `pages/01_SSA_Map.py`. The planner and executor implement against this verbatim.

### Base tiles

- **Tile provider:** `"CartoDB Positron"` (folium built-in; no API key required; free; attribution shown by folium automatically).
- **Rationale:** Light/neutral; renders cleanly at country zoom; doesn't fight the choropleth-style country fills. OSM tiles are too visually noisy at SSA-wide zoom; "no base" is also acceptable but Positron makes coastline and ocean read correctly for users not already familiar with the continent outline.
- **Attribution:** Leave folium's default attribution badge in the bottom-right (license requirement). Do not hide it.

### Country geometry styling

| State | Fill color | Fill opacity | Stroke color | Stroke width |
|-------|-----------|--------------|--------------|--------------|
| Default (unselected) | `#F0F2F6` (Secondary) | 0.7 | `#9AA0A6` (neutral gray) | 1px |
| Selected | `#FF4B4B` (Accent) | 0.6 | `#B71C1C` (darker red) | 3px |
| Hover (any country) | inherits state (default or selected) | inherits + 0.1 (slight brighten) | inherits | inherits + 1px |

**Selected-state redundancy:** color AND stroke-width both change. A user with red/green color-vision difference reads "selected" via the 3px-vs-1px stroke contrast alone. Do not rely on color alone (Accessibility minimum below).

### Tooltip behavior

- **On hover:** show a one-line tooltip with the country **name** (from `country_metadata.name_for(iso3)`). No ISO3 in the hover string — it's redundant for a modeler scanning the map.
- **Format:** plain text, 14px (folium default), no styling overrides.
- **Sticky:** `False` (tooltip follows the cursor; default folium behavior).

### Click interaction

- **Primary action:** click anywhere inside a country polygon writes that country's ISO3 to `st.session_state[COUNTRY_SESSION_KEY]` and reruns the page (D-32, D-36).
- **No confirmation step.** Selection is non-destructive — clicking the wrong country is a one-click correction.
- **No double-click handling.** Single click only.

### Projection, center, zoom

- **Projection:** Web Mercator (folium/Leaflet default; do not change).
- **Initial center:** `[0.0, 20.0]` (lat, lon) — roughly the geographic centroid of SSA.
- **Initial zoom:** `3` (folium scale 1-18; level 3 fits the full SSA extent comfortably in a 600px-tall container at typical desktop widths ≥1280px).
- **Min/max zoom:** `min_zoom=2`, `max_zoom=7`. Below 2 the user can drag the continent off-screen; above 7 the country polygons pixelate and the modeler should be switching to a per-country view (Phase 5 LAYER-06) anyway.
- **Pan/zoom enabled:** yes (folium default). Phase 6 PERF tunes this; Phase 2 just enables it.

### Container sizing

- **Width:** `use_container_width=True` (full content width of Streamlit's `layout="wide"` page — typically ~1100-1500px depending on viewport).
- **Height:** `600px` (fixed pixel value — streamlit-folium requires this; percentages do not work).
- **Behavior on narrow viewports (<800px):** Streamlit-folium handles this by shrinking the iframe width; no special handling required. Modelers run this on laptops at ≥1280px in practice; mobile is not a supported viewport.

## Copywriting Contract

Phase 7 owns per-layer captions (UX-02). Phase 2 establishes the **style** for the page-shell elements that Phase 3-7 inherit, plus the specific copy for this phase's two surfaces (sidebar picker and map page).

### Page-shell copy pattern (inherited by every page from Phase 2 onward)

```
[ st.title ]                <-- page name as Display-role heading, plain noun phrase, no verbs
[ subtitle / one-line ]      <-- one sentence orienting the user (st.write, Body role)
[ optional caption ]         <-- st.caption with "Selected country: <Name>" indicator
[ body content ]
```

Caption style Phase 3-7 must follow (set here so Phase 7 polish has a target):

> `WHO cholera cases for Angola (1949-2024). Source: World Health Organization.`

Form: `<dataset description> for <country name> (<time range>). Source: <provider>.` One sentence. Period at end. No emoji.

### Sidebar picker copy

| Element | Copy |
|---------|------|
| Picker label | `Country` |
| Help-text tooltip (`help=` arg on selectbox) | `Pick a country to scope every view in the app. You can also click a country on the SSA Map page.` |
| Placeholder (only seen if list is empty) | not applicable — `st.selectbox` does not show a placeholder when options are non-empty; if options are empty we go to empty-state below |
| Format function output (per option) | `name_for(iso3)` — country name only, e.g., `"Angola"`. Not `"Angola (AGO)"`. ISO3 is a backend code; users see names. |

### Empty / error states

Follow the Phase 1 pattern: `st.warning` for missing-but-recoverable, `st.error` for crashed/blocked, `st.info` for present-but-empty.

| Condition | Surface | Banner type | Copy |
|-----------|---------|-------------|------|
| `country_metadata.iter_countries()` returns empty | Sidebar picker | (no widget rendered; replace with banner) `st.sidebar.error` | `No countries available. Check that country_metadata.py is populated.` |
| `shapefiles.available_countries()` returns empty (shapefiles subdir missing) | Sidebar picker | `st.sidebar.warning` (rendered ABOVE the picker; picker still renders from metadata) | `No shapefiles found at the configured data root. The picker still works; map clicks will not.` |
| `load_africa_geometry()` returns empty GeoDataFrame | Map page (replaces map) | `st.warning` | `SSA shapefile not found at <path>. Check Data Status, or set the data-root override in the sidebar.` |
| `load_africa_geometry()` raises `SchemaMismatchError` | Map page (replaces map) | `st.error` | `SSA shapefile is malformed (expected ISO3 attribute missing). See logs for details.` |
| `country_metadata` ↔ `shapefiles.available_countries()` divergence detected (D-29) | Log only (no UI surface) | `logging.warning` | `Country metadata / shapefile drift: countries in metadata but not in shapefiles: <list>. Countries in shapefiles but not in metadata: <list>.` |
| User changes dropdown OR clicks map | (no banner; instant rerun) | none | none — Streamlit's reactive rerun IS the feedback. If rerun >100ms is a concern, that's Phase 6 PERF, not Phase 2. |

### Primary CTA

Phase 2 has no traditional "submit button" CTA — the country picker and map-click ARE the action surface, and they fire on change with no commit step. For the `gsd-ui-checker` Copywriting dimension:

| Element | Copy |

| Primary CTA (map) | `Click a country to select it` (the subtitle text IS the call to action) |

## Page-Shell Pattern (inherited by Phase 3-7)

This is the canonical structure every page in the app follows from Phase 2 onward. Document it here so Phase 3's planner doesn't have to re-derive it. Page filename convention is `NN_Page_Name.py` with two-digit zero-padded prefix (CLAUDE.md §4).

```python
"""<one-line module docstring>"""
from __future__ import annotations

import streamlit as st

# 1. set_page_config MUST be the first Streamlit call on the page.
st.set_page_config(page_title="<Page Name>", layout="wide")

# 2. Render the shared sidebar before any other content (P9 mitigation —
# keeps the data-root override AND country picker widgets alive across
# navigation).
from mosaic_dashboard.ui.sidebar import render as render_sidebar  # noqa: E402
render_sidebar()

# 3. All other imports.
from mosaic_dashboard.config import COUNTRY_SESSION_KEY  # noqa: E402
from mosaic_dashboard.data import country_metadata  # noqa: E402
# ... domain imports ...

# 4. Page title (Display role).
st.title("<Page Name>")

# 5. One-sentence subtitle (Body role).
st.write("<One sentence orienting the user.>")

# 6. Currently-selected-country indicator (Label role) — every page that
# scopes by country renders this immediately under the subtitle.
iso3 = st.session_state[COUNTRY_SESSION_KEY]
st.caption(f"Selected: {country_metadata.name_for(iso3)} ({iso3})")

# 7. Body content (figures, tables, map, charts).
# ...

# 8. Trailing caption (Phase 7 will fill these in for layer pages — Phase 2
# uses the attribution caption below the map).
# st.caption("<Phase 7 layer caption goes here.>")
```

**No footer.** No global page wrapper. No custom CSS injection. Phase 3 plans inherit this skeleton verbatim and only fill in step 7. Phase 4 (overlays) extends step 7 but keeps the rest identical.

**Sidebar widget order** (rendered by `ui/sidebar.py::render()`, top-to-bottom):

1. `st.sidebar.header("Mosaic Dashboard")` — branding header (Heading role).
2. `st.sidebar.text_input("Data root override (session only)", key=SESSION_KEY, ...)` — Phase 1's data-root override (do not move).
3. `st.sidebar.divider()` — visual separator between "what data to use" and "what country to look at" (introduced in Phase 2).
4. `st.sidebar.selectbox("Country", options=..., key=COUNTRY_SESSION_KEY, format_func=country_metadata.name_for, help="Pick a country to scope every view in the app. You can also click a country on the SSA Map page.")` — Phase 2's country picker.

Streamlit's auto-discovered page list renders below this — that's Streamlit chrome, not ours to style.

## Accessibility Minimum

| Concern | Contract |
|---------|----------|
| Color-vision difference | Selected country differs from unselected by BOTH color (red vs gray) AND stroke width (3px vs 1px). Stroke-width contrast alone is sufficient to identify selection in monochrome or with red/green deuteranopia. |
| Keyboard navigation | Streamlit selectbox is keyboard-reachable by default (Tab focus, arrow keys, type-ahead). Do not break this with custom CSS. The folium map is mouse-primary; users without a pointing device fall back to the sidebar dropdown — both inputs write to the same session_state key, so the map is a convenience layer, not a requirement. |
| Contrast | All foreground/background pairings inherit Streamlit's default theme, which passes WCAG AA at 16px body. The accent red `#FF4B4B` on the secondary gray `#F0F2F6` map fill passes WCAG AA (contrast ratio ≈ 3.2:1 for non-text graphical elements; minimum is 3:1). |
| Screen reader for the map | folium iframe is not screen-reader-friendly (Leaflet limitation). The sidebar selectbox IS — that's the assistive-tech path. Document this in code comments on `01_SSA_Map.py`. Do NOT attempt to add ARIA labels to folium output; you'd be patching an iframe whose content you don't control. |
| Focus indicators | Streamlit defaults; do not override. |
